# Plantilla de Proyecto Genérico con Aider

Esta plantilla proporciona una estructura base y un conjunto de scripts para inicializar y gestionar sesiones de [Aider](https://aider.chat/) de forma automatizada en cualquier tipo de proyecto.

## Características

- **Carga automática de entorno**: Lee variables desde `.env`.
- **Contexto fresco**: Genera un resumen del estado de Git antes de iniciar.
- **Selección interactiva de modelos**: Permite elegir entre múltiples modelos de IA configurados.
- **Memoria persistente**: Mantiene un registro de la fase actual, commits recientes y tareas pendientes.
- **Reglas y convenciones**: Incluye archivos base para guiar el comportamiento de Aider.
