# LightTTS API Examples

This directory contains example scripts for interacting with the LightTTS API endpoints.

## Scripts

### Voice Cloning
- `clone_voice_cosyvoice3.py` - Clone a voice using CosyVoice3 model
- `clone_voice_voxcpm.py` - Clone a voice using VoxCPM model

### Text-to-Speech (TTS)
- `tts_cosyvoice3.py` - TTS synthesis with CosyVoice3 (streaming/download, studio/fast modes)
- `tts_voxcpm.py` - TTS synthesis with VoxCPM (streaming/download, studio/fast modes)

### Voice Management
- `list_voices.py` - List all available voices
- `delete_voice.py` - Delete a voice by ID
